# Brainstorm (Template)

## Goal
Clarify the problem, success criteria, and scope boundaries before coding.

## Workflow
1. Ask one focused question at a time.
2. Offer concrete options when tradeoffs exist.
3. Capture decisions as stable requirements.
4. Separate product decisions from implementation details.

## Output
- A concise requirements note with:
  - Problem frame
  - Requirements
  - Scope boundaries
  - Success criteria
